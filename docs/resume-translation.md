# HCOM Resume Translation Notes

This document converts the HCOM project work into recruiter-ready resume bullets for **frontend** and **full-stack / architecture** roles.

The focus is on **honesty, clarity, and measurable contributions**, highlighting your **solo developer work** and architectural thinking.

---

## Frontend / Blazor-focused bullets

- Designed and implemented a modular SPA UI for a healthcare management system, including **modal-based CRUD, notifications, and data filtering**, prioritizing usability for novice users.
- Built **stateful layouts and reusable components** in Blazor to replace multi-page Django workflows, reducing frontend-backend coordination overhead.
- Developed a **toast/notification panel system** fully in C#, ensuring real-time feedback without JavaScript interop.

---

## Full-Stack / Architecture-focused bullets

- Migrated a healthcare management system from Django to Blazor SPA, **preserving UX invariants** and simplifying state management across the stack.
- Architected **end-to-end data flow and component layouts**, including modal CRUD, filtering, and notifications, to support **scalable modular deployment**.
- Evaluated trade-offs for REST API, React/Vue, and CORS considerations, opting for **single-language (C#) architecture** to streamline development and reduce cognitive load.
